# Reflections

A running journal of what actually happened, next to the plan of what was supposed to happen.
The plan folders are the map; this folder is the trip log.

## How it works

1. **You ask for one.** Say "reflect on last week", "reflect on October", or "reflect on Weeks 5 to 7".
   Claude pulls the period's activities from Garmin Connect (cycling, running), strength sessions from
   the BAI Daily Manager planner, and the sessions that were scheduled on the calendar, then writes a
   new file here from `_template.md`.
2. **Claude fills the top half.** The data tables and the "Claude's reflection" section are written
   for you. They stay honest: what happened is listed, what did not happen is noted once without
   lecturing, and the reflection is about what the completed work says and what to carry forward.
3. **You fill the bottom half.** The "Your notes" section is yours. Edit the file directly on GitHub
   (pencil icon on the file page), in any text editor, or dictate to Claude and it will paste it in.
   Nothing you write there is overwritten; Claude only appends below the agreed adjustments after you
   have added notes, and only when asked.
4. **Adjustments feed the next month.** When the next month's workouts are generated, Claude reads
   the latest reflection first. The "Agreed adjustments" section is the contract between the two.

## File naming

| Scope | Name | Example |
|---|---|---|
| One week | `YYYY-Www.md` (ISO week, Monday to Sunday) | `2026-W42.md` |
| Several weeks | `YYYY-Www to Www.md` | `2026-W42 to W45.md` |
| One month | `YYYY-MM - Month N.md` | `2026-11 - Month 2.md` |
| Lead-in or custom | `YYYY-MM-DD to YYYY-MM-DD.md` | `2026-09-13 to 2026-10-13.md` |
